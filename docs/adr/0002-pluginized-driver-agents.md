# ADR-0002：驱动插件化——独立进程，按需下载

- 状态：已接受（2026-09-11，用户选定「照 GoNavi 的路子」）
- 关联卡片：#13 范围清单

## 背景

体积红线已取消（ADR-0006），插件化不再为省体积，理由变为：加数据源不发主程序新版、第三方可写驱动。参考实现即 GoNavi：驱动独立进程、按需下载到 `~/.gonavi/drivers/`、索引在 `GoNavi-DriverAgents-Index.json`。本机实测其驱动代理进程每个 ~4.3 MB RSS。

实测教训：GoNavi 连跑数天后残留 **7 个僵尸 sqlite 驱动进程**（本机 `ps aux`，2026-09-11）——驱动生命周期没人管。

## 决策

1. 驱动代理 = 独立 Go 二进制，一种数据源一个，主程序经 **stdio JSON** 与之通信（与 MCP 子命令同构）。
2. 按需下载：远端索引 JSON（驱动名 → 版本 → 平台产物哈希），首次使用某数据源时下载到 `~/.lazydb/drivers/`；索引校验版本兼容（主程序声明所需协议版本区间）。
3. **生命周期归 `internal/driverhost/` 统一管**：连接关闭或空闲超时即退出驱动进程；后端退出时全部回收。僵尸进程是 GoNavi 的实际缺陷，lazydb 必须不重演。

## 后果

- 首次使用需联网下载；离线环境用不了新数据源（内置可直连 MySQL 驱动做 tracer bullet，不依赖下载）。
- 三平台 × N 驱动的构建矩阵进入 CI。
- 驱动与主程序协议演进要带版本协商。
