# ADR-0005：MCP——独立子命令，默认只读

- 状态：已接受（2026-09-11；推翻早期「界面常驻」选择，依据新证据）
- 关联卡片：#8 MCP 形态、#10 MCP 写权限

## 背景

GoNavi 实证：同一二进制带 `mcp-server` 子命令，界面不开也能用（本机 `claude mcp list` 可见，多个实例常驻）。「界面必须开着」对 AI 场景是硬伤。MCP 官方 Go SDK Tier 1 stable（v1.7.0）。#13 定了数据可写 → AI 经 MCP 误删数据的风险真实存在。

## 决策

1. `lazydb mcp-server`：AI 客户端直接拉起，stdio 传输，读同一份连接配置与缓存（并发安全靠 ADR-0004 的 WAL + 文件锁）。
2. **默认只读**：拒绝一切写语句。写权限需 `--allow-write` 或配置显式开启。
3. 工具面（第一版）：列连接/库/表/字段、查 DDL、执行只读查询、搜结构、查历史。

## 后果

- 配置与缓存格式成为跨进程契约，升级要向后兼容。
- 「每次写要界面确认」被否：与「界面不开」矛盾；`--allow-write` 开启即责任转移给使用者。
